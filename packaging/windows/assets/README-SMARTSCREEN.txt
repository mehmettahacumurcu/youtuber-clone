WINDOWS SMARTSCREEN AND INSTALLATION NOTICE

Early YouTuber Studio test installers may be unsigned. Windows SmartScreen can
therefore show an "unrecognized app" warning even when the downloaded file
matches the published SHA-256 checksum. Verify the checksum against the release
page before running the installer. Do not bypass a warning for a file obtained
from another source or with a different hash.

The installer runs per user without administrator rights and installs the
launcher under Local AppData. Large models, RAG data, and voice components are
downloaded later from the signed production catalog; they are not hidden inside
the setup EXE. Uninstall can retain those downloads for reinstall or remove only
paths carrying the matching YouTuber ownership marker.
